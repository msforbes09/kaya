# Stack decisions (from the original handoff)

Do not relitigate unless something breaks.

- **Hono, not Next.js.** One long-lived WebSocket process; no request/response framework needed.
- **ElevenLabs for both directions.** Scribe v2 Realtime for STT, browser → ElevenLabs directly with a single-use token minted by the server. TTS server side.
- **Postgres + pgvector, not MariaDB.** Embeddings column exists but is unused in v1.
- **Sentence-chunked TTS.** Each sentence is one TTS request. Frames carry a 4-byte sequence number so the client can play in order.
- **Permission tiers in `server/src/agent/permissions.ts`.** Reads auto-allowed, edits silent, Bash screened against `destructive-patterns.json`, destructive commands ask the human over the socket.
- **Naming.** The assistant is Kaya. Env vars are `KAYA_*`, the MCP server is `kaya`, the Postgres container is `kaya-pg`.
- **Runs on the Mac, not a remote box.** `KAYA_WORKSPACE=/Volumes/Developer/Projects/Personal`. No cloning; Kaya works on the live checkouts. Server binds to localhost or Tailscale only.
